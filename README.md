# 🔐 SecureVaultPro

SecureVaultPro is a Zero-Trust secure file storage system with encryption, TOTP authentication, IDS monitoring, and tamper-proof logging.

---

## 🚀 Features

- 🔒 AES-256 Encryption (Per-user key)
- 🔑 TOTP Authentication (Google Authenticator)
- 📂 Secure File Upload & Download
- 🔍 Encrypted Search (ORE-based)
- 🚨 Intrusion Detection System (IDS)
- 🧾 SEAL Logging (Tamper-proof logs)
- 🛡 Zero Trust Architecture

---

## 🛠 Tech Stack

- Backend: Python (Flask)
- Frontend: HTML, CSS
- Database: Google Sheets / SQLite
- Security: Cryptography, PyOTP

---

## 🔐 Security Model

- Multi-layer authentication
- No direct data exposure
- Encrypted storage
- Behavioral monitoring (IDS)
- Audit logging (SEAL)
