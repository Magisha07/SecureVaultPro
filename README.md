# 🔐 SecureVaultPro

SecureVaultPro is a Zero-Trust secure file storage system that ensures encrypted data access using AES encryption, TOTP authentication, ORE-based search, and IDS monitoring with SEAL logging.

---

## 🚀 Key Features

- 🔒 AES Encryption for secure file storage
- 🔍 ORE-based Encrypted Search
- 🔑 TOTP Authentication (Google Authenticator)
- 📂 Secure Upload & Download
- 👁 View Encrypted Data
- 🚨 Intrusion Detection System (IDS)
- 🧾 SEAL Logging (Tamper-proof logs)
- 🛡 Zero Trust Architecture

## 🔐 Security Architecture

- AES Encryption for file protection
- Per-user key management (KMS)
- TOTP-based Zero Trust access
- Behavioral Intrusion Detection System (IDS)
- SEAL logging for tamper-proof audit trails

---

## 🛠 Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS
- **Database:** Google Sheets / SQLite
- **Security:** Cryptography, PyOTP
